<h2>🏆 FEATURED PROJECT</h2>

<h3>🥗 AI-Based Food Nutrition Estimator</h3>

<p align="center">
  <a href="https://food-nutrition-estimator-three.vercel.app">
    <img src="https://img.shields.io/badge/🌐_LIVE_DEMO-00F0FF?style=for-the-badge&labelColor=0d1117" />
  </a>
  <a href="https://github.com/YashGawad/food-nutrition-estimator">
    <img src="https://img.shields.io/badge/💻_SOURCE_CODE-181717?style=for-the-badge&logo=github" />
  </a>
</p>

<p align="center">
  <b>AI • Computer Vision • Full Stack • Cloud</b>
</p>

<p>
  A cloud-based full-stack application that analyzes food images and estimates
  calories and nutritional information using deep learning.
</p>

**🔬 AI / Computer Vision**

* Trained and deployed a CNN/MobileNet image classification model using TensorFlow.
* Identifies food items from user-uploaded images.
* Estimates nutritional information based on recognized food items.

**⚙️ Full-Stack Architecture**

* Built the frontend using React.js.
* Developed RESTful APIs using Spring Boot.
* Integrated the Spring Boot backend with a Python AI microservice.
* Used MySQL for application data.

**☁️ Cloud Infrastructure**

* Deployed application components using AWS EC2.
* Used AWS RDS for database infrastructure.
* Used AWS S3 for cloud storage.
* Applied IAM roles for secure access control.
* Used Docker for containerization.

**Tech Stack**

`React.js` `Spring Boot` `Python` `TensorFlow` `MySQL`
`AWS EC2` `AWS RDS` `AWS S3` `IAM` `Docker`

## Quick Start (example)

Clone the flagship project and run locally:

```bash
git clone https://github.com/YashGawad/food-nutrition-estimator.git
cd food-nutrition-estimator
# frontend
cd web && npm install && npm run dev
# backend
cd ../api && ./mvnw spring-boot:run
```

Adjust commands per repository structure.

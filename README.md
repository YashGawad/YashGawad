### 🥗 AI-Based Food Nutrition Estimator
> **Deep Learning • Computer Vision • Full-Stack Microservices • AWS Production Cloud**

<p>
  <a href="https://food-nutrition-estimator-three.vercel.app" target="_blank">
    <img src="https://img.shields.io/badge/%F0%9F%8C%90_LIVE_DEMO-00F0FF?style=for-the-badge&labelColor=0d1117" alt="Live Demo" />
  </a>
  &nbsp;
  <a href="https://github.com/YashGawad/food-nutrition-estimator" target="_blank">
    <img src="https://img.shields.io/badge/%F0%9F%92%BB_SOURCE_CODE-181717?style=for-the-badge&logo=github" alt="Source Code" />
  </a>
</p>

An intelligent cloud-native full-stack application that accurately detects food items from user images and estimates calorie counts and macro-nutritional distributions in real-time.

* 🔬 **Computer Vision Engine**: Trained and fine-tuned a CNN / MobileNet image classification model in **TensorFlow** to recognize various food classes and infer nutritional metrics.
* ⚙️ **Decoupled Backend Architecture**: Architected **Spring Boot REST APIs** communicating with a dedicated **Python AI inference microservice**.
* ☁️ **Cloud & Production Infrastructure**: Deployed on **AWS EC2**, connected to **AWS RDS (MySQL)**, with media storage powered by **AWS S3**, fine-grained **IAM roles**, and **Docker** containerization.

  <img src="https://img.shields.io/badge/React.js-20232A?style=flat-square&logo=react&logoColor=61DAFB" />

</p>

    1. <b>Image Ingestion:</b> React frontend captures user image and streams it via Spring Boot multipart handler.<br>
    2. <b>AI Inference:</b> Python microservice runs MobileNet inference, generating bounding detections and softmax probabilities.<br>
    3. <b>Nutritional Mapping:</b> Spring Boot correlates food classes with USDA nutritional datasets in MySQL.<br>
    4. <b>Cloud Asset Pipeline:</b> Original images archived in AWS S3 with signed URI access.

> **Mission Brief:** An end-to-end intelligent computer vision platform that analyzes meal imagery, accurately recognizes food items, and estimates immediate nutritional and caloric metrics.

- 📊 **Automated Macro Calculations**: Real-time calorie, protein, fat, and carbohydrate estimations.
- 📈 **Interactive Dietary Dashboard**: Personalized user tracking, telemetry, and nutritional history logs.
- ⚡ **Full-Stack Cloud Core**: Built with `React`, `Spring Boot`, `TensorFlow`, `MySQL`, and `AWS Cloud`.

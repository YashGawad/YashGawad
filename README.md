### 🥗 AI-Based Food Nutrition Estimator

> **AI/ML • Computer Vision • Full-Stack Application • AWS Cloud Deployment**

<p>
  <a href="https://food-nutrition-estimator-three.vercel.app" target="_blank">
    <img src="https://img.shields.io/badge/%F0%9F%8C%90_LIVE_DEMO-00F0FF?style=for-the-badge&labelColor=0d1117" alt="Live Demo" />
  </a>

  &nbsp;

  <a href="https://github.com/YashGawad/food-nutrition-estimator" target="_blank">
    <img src="https://img.shields.io/badge/%F0%9F%92%BB_SOURCE_CODE-181717?style=for-the-badge&logo=github" alt="Source Code" />
  </a>
</p>

A cloud-based full-stack application that analyzes user-uploaded food images and estimates calorie and nutritional information using an AI-based image classification approach.

* 🔬 **AI & Computer Vision**: Used **Python and TensorFlow** with a CNN / transfer-learning approach to analyze food images and estimate nutritional information.

* ⚙️ **Full-Stack Integration**: Built RESTful APIs to connect the **React.js frontend** with the Python/TensorFlow AI service and manage application data using **MySQL**.

* ☁️ **AWS Deployment**: Deployed the React frontend on **Vercel** and backend/AI services on **AWS EC2**, with MySQL hosted on **AWS RDS** and food images stored in **Amazon S3**.

* 🐳 **Containerization & Security**: Containerized the Python AI service using **Docker** and configured **AWS IAM** access controls for cloud resources.

### 🛒 LocalCommerce — Multi-Tenant Local Commerce Platform

> **React.js • Node.js • Express.js • PostgreSQL • REST APIs • Vercel • Render**

<p>
  <a href="https://localcommerce-pearl.vercel.app/" target="_blank">
    <img src="https://img.shields.io/badge/%F0%9F%8C%90_LIVE_DEMO-00F0FF?style=for-the-badge&labelColor=0d1117" alt="Live Demo" />
  </a>

  &nbsp;

  <a href="https://github.com/YashGawad/localcommerce" target="_blank">
    <img src="https://img.shields.io/badge/%F0%9F%92%BB_SOURCE_CODE-181717?style=for-the-badge&logo=github" alt="Source Code" />
  </a>
</p>

A multi-tenant local commerce platform designed with separate experiences for customers, businesses, delivery operations, and administrators.

* 🏪 **Multi-Tenant Platform**: Built separate **Customer, Business, Delivery, and Admin** experiences for independent local businesses.

* 📦 **Store Management**: Designed store-scoped management for **products, inventory, orders, customers, staff, fulfillment, discounts, analytics, and reviews**.

* 🔐 **Role-Based Access**: Implemented role-based access and workflows supporting **pickup and local delivery** operations.

* 🌎 **Product Architecture**: Architected a global product and store-specific listing model supporting cross-store product discovery while preserving independent pricing, inventory, and fulfillment rules.

* ⚙️ **Backend & Database**: Built a **Node.js/Express REST API with PostgreSQL and JWT-based authentication** for catalog, ordering, and multi-tenant data management.

* ☁️ **Deployment**: Deployed the frontend using **Vercel** and backend/database using **Render**.
